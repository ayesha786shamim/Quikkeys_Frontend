# Quikkeys Frontend

Welcome to the **Quikkeys Frontend** repository! This project is the frontend interface for **Quikkeys**, offering an engaging and interactive typing speed test powered by AI-generated paragraphs. Built with modern web technologies, it ensures an intuitive and responsive user experience.

---

## 📝 About

**Quikkeys Frontend** is designed to provide users with an intuitive interface to test their typing speed and accuracy. The app presents AI-generated paragraphs of varying difficulty levels and tracks users' typing performance, providing feedback on words per minute (WPM), accuracy, and errors. It is built with **React** and incorporates **Axios** to fetch data from the backend API, ensuring dynamic updates and smooth interactions.

---

## 🚀 Features

- **Typing Speed Test**: Allows users to measure their words per minute (WPM) as they type the generated text.
- **Accuracy Calculation**: Tracks typing accuracy and provides real-time feedback.
- **Error Tracking**: Identifies typing errors and helps users improve.
- **Difficulty Levels**: Choose from easy, medium, or hard difficulty to match your typing skills.
- **AI-Generated Paragraphs**: Uses AI-generated content for a diverse and challenging typing experience.

---

## ⚙️ Technologies

- **React**: A JavaScript library for building user interfaces.
- **Axios**: A promise-based HTTP client for fetching data from the backend API.
- **CSS**: For styling the components and creating a visually appealing interface.
